# Contribuir

O CEME está sob a [PolyForm Noncommercial 1.0.0](LICENSE). O uso comercial é
licenciado à parte, caso a caso.

Antes de o teu primeiro pull request poder entrar, assina o [Contributor
License Agreement](CLA.md): comenta no pull request com exactamente

> I have read CLA.md and I agree to it, for my past and future contributions to CEME.

Um bot verifica cada pull request e regista a assinatura, portanto só assinas
uma vez (outra vez só se o CLA.md mudar). O copyright do que escreves continua
a ser teu. O acordo deixa o mantenedor incluir a tua contribuição nas licenças
comerciais; a versão pública continua pública.

Dados de terceiros (tarifas da ERSE, preços OMIE/MIBEL, ...) não são teus para
licenciar: diz de onde vêm e em que termos, para irem para o
[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

Como o código está organizado, as regras que segue e como correr os testes:
[CLAUDE.md](CLAUDE.md) e [README.md](README.md).
